Chrome Lock

Settings for this Chrome profile only. Every profile on this computer has its own password and its own locked session.

Password

No password is set, so this extension currently does nothing on this profile: no locking, no keyboard shortcut, no idle timer.

Changing your password re-seals your key under the new one. Any session you have locked right now stays locked and will open with the new password.

Locking the screen counts as idle straight away, whatever this says.

Paste this into another profile's settings, or into the managed-preferences plist under escrowBundle to hand it to every profile at once. The private half is sealed under the master password, so this text reveals nothing.

Change the master password

The key itself does not change, so every profile keeps working and no locked session is stranded.

The master password stops opening this profile, including any session locked right now. Your own password is unaffected and still opens everything.

What this does, and what it doesn't

  • Locking encrypts your open tabs and closes them. The list is never written to disk unencrypted.
  • Turning the extension off does not bring your tabs back — nothing but your password can decrypt them.
  • It does not stop anyone from using this profile once the extension is off. Your history and saved passwords are not protected.
  • If you forget your password and no parent unlock is available, the locked tabs are gone for good. Nothing else is lost.
